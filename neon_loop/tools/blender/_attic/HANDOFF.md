* R1d2 rear: `fold_report.py [out.png]` (per-station fold table + sections plot: turn T, roll theta, barrel B2, radius, arc path error, G1 gap to the glass strip), `fold_fit.py opt|eval` (design functions), `dihedral_u.py x0 x1` (dihedral along U), `rear_overlay.py --out dir --render-dir dir --views r81,p017,high [--ear | --arc-table]` (model arc / curves on photo | render pairs; `--arc-table` = arc vs photo reading in 3-D and px), `measure_rear.py`, `measure_roofline.py`, `shots_r1d2.sh` (Cycles r81 / p017 / p018 / high with `--glass-dark`, reflect h / v, overlays, tables).
