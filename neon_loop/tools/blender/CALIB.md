# 相机统一校准（CALIB，2026-10-25）

全部外观照片的相机放在**一个**联合解算（bundle adjustment）里求解。这样每台相机都和同一组 3D 地标、同一对车轮一致，不再是“每张照片各配各的”。
校准后的相机已经写进 `render_ref_views.py` 的 `VIEWS`，`cam.py` 和 overlay、mask 工具会自动用上。旧相机保留为 `<名>_v1`。

## 怎么做的

- **未知量**
  - 每张照片一台相机：位置 3、朝向 3、焦距 1。主点固定在图像中心；`thrust`、`high` 沿用原来的 shift。
  - 15 个地标点：成对的点左右对称，共用 (x, |y|, z)。
  - 车轮轮辋：3D 圆，前后各一组。
    - 轴心 x 固定，是尺度和原点的基准（gauge）：前 −1.487，后 1.61，即模型的轮心。
    - 轴高、轮辋外沿 |y|、半径都是未知量。沙漠组 p011 / p012 的轮子另算一组。
  - 前轮转角：每张照片一个。
- **观测**
  - 手读点：放大 4–9 倍、带像素格的裁切图上读取，每点带 σ。见 `calib/crop.py`。
  - 轮辋外沿：沿径向扫描亮盘→暗胎的边缘点，再做稳健椭圆拟合（`calib/wheel.py`、`saverim.py`）。残差用到投影圆锥曲线的 Sampson 距离。
  - 喷口环心：亮环外沿拟合椭圆，拟合残差 0.1–0.3 px（`calib/ring.py`）。
  - 轮胎接地点：z = 0，用来固定高度基准。
  - p012 的地平线：干湖床远端那条线。
- **解法**
  - Huber 稳健 Levenberg–Marquardt，数值雅可比，只依赖 numpy（`calib/bundle.py`）。
  - 有旧相机的照片加很弱的先验：位置 σ 0.6 m，焦距 15 %。
  - 前轮正直的照片，转角先验为 0 ± 2°。
- **复现**
  - 运行 `python3 tools/blender/calib/solve.py`，约 3 分钟，输出 `calib/result.json`。
  - 检查图：`python3 tools/blender/calib/overlay.py <dir>`。图中绿 = 读点，红 = 校准相机重投影，橙 = 旧相机。

### 独立核对（这些量不在拟合里）

- **p011 地平线**：校准相机预测左侧地平线在 v = 679.5，照片是 ≈ 680。
  - 右侧是 643 对 630，那里是雾霭边界，不可靠。
- **牌照比例**：宽 / 高 = 0.337 / 0.166 = 2.03，美国牌照是 2.0。
  - 四个角是自由点，比例没有被约束。
  - 绝对尺寸 33.7 cm 比美国牌照 30.5 cm 大 10 %。如果是美国牌照，说明模型整体尺度偏大约 10 %。
  - 尺度是基准选择（轴距），不影响外观，记录备查。
- **拟合内部的一致性**（不算独立）：
  - 7 个轮胎接地点残差 ≤ 5.5 px（σ 3 px）。
  - r81 后胎外沿比“轮辋 + 4 cm”再宽约 2 cm（|y| ≈ 1.15）。
  - p012 地平线残差 ≤ 3 px。

## 结论

1. **REFS.md 里“r81 / high 一组与 p018 / p017 一组车尾高度差约 5 cm”的冲突是相机造成的，不是形状分歧。**
   - 联合解算后，r81、p018、p017 在车尾的残差全部 ≤ 3 px。
   - 统一的车尾高度：面板外上角 z 0.990，灯条 0.941，外下角 0.850。
2. 旧相机里最差的是 thrust（67 px）、r81 / p017 / p013（13–14 px）和 p003（位置根本不对）。p018 本来就基本对（3 px）。
3. p016、p017、p003 的前轮是**转向**的（−18°、+19°、+23°，影棚造型常用）。用这三张比对前轮时，模型前轮也要按这个角度转，否则轮子会对不上。
4. 当前模型与校准地标的主要差别（下一阶段核实）：
   - 前轴低 3.7 cm，前后轮不同大小。
   - 轮距每侧宽约 8 cm。
   - 牌照、喷口、扩散器区比模型靠后 10–19 cm，并且更高。
   - 后窗下角靠后 5 cm、低 3.7 cm。

## 加一张照片

1. 用 `calib/crop.py` 读点，写进 `calib/picks.json`；地标定义见上表，σ 按清晰度给 1–3 px。
2. 车轮用 `calib/saverim.py`，喷口用 `calib/ring.py`。
3. 在 `calib/init_views.json` 的 `new` 里给一个大致初值。离得太远会收敛到错的局部极小，p003 就是先用网格搜索找到初值的。
4. 运行 `solve.py`，把 `result.json` 的 view 写进 `VIEWS`。

# 第二阶段：特征线三维重建（2026-10-25）

用第一阶段的统一相机，把车身上看得见的线逐张照片描出来，再用所有照片联合求每条线的三维位置。只用真实的线：面与面的折棱、玻璃与车身的交界、黑白分界、缝、灯条。轮廓线（剪影）随视角变化，不是车身上的固定线，留给第三阶段的曲面拟合。

## 做法

- **描线**（`calib/trace.py`）：
  - 把当前模型对应的曲线用校准相机投到照片上作初值。
  - 沿法向 ±10–45 px 找图像上最强的边：亮暗台阶、细暗缝或细亮灯条，极性按线指定。
  - 亚像素定位，再用稳健平滑剔掉跳点。
  - 每条线每张照片都出检查图（绿 = 采用，红 = 剔除），逐张目检。错边的视角已经删掉或改了种子，见 `linecfg.py` 注释。
- **三维拟合**（`calib/lines.py fit`）：
  - 每条线是一个轴上的图（x、y 或 z → 另两个坐标），用三次 B 样条，左右对称。
  - 最小化所有照片里描线点到投影曲线的像素距离（Huber），加二阶平滑和到初值的弱拉力（σ 15 cm）。
  - 可以加第一阶段的地标作端点锚（1 cm）。
  - 轮拱只用正侧视（p018、p001），|y| 固定为 1.03：轮拱唇是卷边，斜视角下看到的是轮廓，不是固定线。
- **真实不确定度**（`calib/lines.py cv`）：
  - 留一法：每次去掉一张照片（两侧一起）重新拟合，用刀切法（jackknife）算每个坐标沿线的 σ。
  - 形式误差太乐观（< 1 mm），这个 σ 才反映“这个数靠几张照片撑着、它们是否一致”。
- **对比与出图**（`calib/lines_report.py <dir>`）：
  - 三视图：侧视、俯视、后视。蓝 = 当前模型，红 = 照片线，橙 = 留一法 σ > 3 cm 的段，绿 = 地标和车轮。
  - 每张照片的叠线图。
  - 偏差表。
  - 没有 design2 曲线的线（轮拱、前后灯条），从 GLB 取模型对应特征：`calib/model_feat.py`。
- **复现**：

  ```
  python3 tools/blender/calib/lines.py trace
  python3 tools/blender/calib/lines.py fit
  python3 tools/blender/calib/lines.py cv
  python3 tools/blender/calib/lines_report.py <dir>
  ```

  结果在 `calib/lines/fit.json`：每条线 200 个点、jackknife σ、各照片残差。

- 侧面线的宽度：L_side、l3、wl 的 \|y\|。
- 尾部横线的前后位置：tail_top 的 x。

用剪影（外轮廓）加第二阶段的线，把车身形状改向照片。形状改动先做成默认关闭的开关，预览确认后再采用。

## 工具

- **剪影对比**（`calib/silhouette.py MASKDIR OUTDIR 视角...`）：
  - `mask_views.py` 用校准相机渲模型遮罩。沿模型外轮廓每 6 px 取一点，在照片亮度上沿外法向 ±30 px 找车 / 背景交界：车侧与背景侧中值的中点，取最外一次穿越。
  - 对比度 < 18 的点不用（黑色下部对暗地面等）。
  - 出图 `<视角>_sil.jpg`：红 = 照片更靠外（模型小），蓝 = 模型大，绿 = |d| < 3 px。数据在 `sil.json`。
- **换成米**（`calib/silmetric.py OUTDIR`）：
  - p013 俯视：每 0.2 m 的半宽 |y|。
  - p018 侧视：中面上的顶线 z。
  - 后视 r81 / p012 / p019：x = 1.65 平面上的 |y|(z)。后视点的真实 x 不确定，这组数噪声 ±4 cm，只作旁证。
- **线的核对**（`calib/linecheck.py [线...]`）：当前模型（带本次的 QF_* 环境，含 shell2 的位置场）的曲线投到照片，与第二阶段描线比，给每条线每张照片的 rms px。
