## 用哪张图定什么（冲突时的裁决规则）

1. **前后位置**（车头、车尾 x）：以能看到车轮的视角为准——p018、p016（车头），r81、p017（车尾）。
2. **俯视形状**：p013（校准后与 016 / 018 同一套地标，比例可直接用；车头绝对位置仍以有车轮的视角为准）。
3. **高度**（z）：p018 侧视为主，r81 正后复核。
4. **两张高可信度照片互相矛盾**时，不要自己选一边：用 3 行报告（两边各要求多少、差多少），由协调者裁决。先确认用的是校准机位（2026-10-25 前的多数“矛盾”是机位不一致造成的）。
5. 新匹配一张照片的机位，要在至少 3 处**这轮不改动**的部位上验证（如车轮、车尾、车顶线），残差写进报告。现在的做法是把它加进统一校准（CALIB.md「加一张照片」）。
6. 3D 位置优先用 CALIB.md 的校准地标（σ 5–10 mm）；p016 / p017 / p003 的前轮是转向的（−18° / +19° / +23°），比对前轮时要按此转轮。
