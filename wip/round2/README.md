## 用户裁决（第二轮的最高准则）

1. "所有的规则都推翻吧，那些规则是过去的产物不准确的（当时用的是未校准相机），请按你的推荐进行重构。"——SPEC / HISTORY 里带日期的旧裁决不再约束，**以校准照片和地标为准**。
2. "确保整车的各个面、线条都平顺不扭曲不拱起之类，跟原车一致，面板和线条可以拉伸改变，不必拘泥。"——每个面平整或单一曲率顺滑，每条棱笔直利落（8 mm 圆角），只在照片显示的地方做软过渡；斑马纹（`--reflect h|v`）在平面上是整块 / 直带，在曲面上单调弯曲，不许有钩、环、旋涡、波纹。
3. 子代理尽量用 Sonnet。

## 完成标准（协调者建议，用户同意"这一轮做完换本机"）

- 全车斑马纹干净：没有扭曲、拱起、钩形、环。
- lock / smooth / budget / npm test / clearance 全过，浏览器里比赛和展厅都没有报错。

## 本机工作方式

- Blender 5.2：`export BLENDER=/Applications/Blender.app/Contents/MacOS/Blender`（脚本默认就是这个路径）。命令见 `neon_loop/tools/blender/AGENT_GUIDE.md`。
- 先把本目录的共用说明 `BRIEF.md` 发给每个子代理（它是云端给代理的说明，路径已改成本机可用的写法）。
- 同时最多 2 个代理；迭代用 `tools/blender/fast_preview.py`（裸壳）和半分辨率、16 采样的渲染，全分辨率对照图只在最后出一次。
- 三段分区，避免改同一块面板：车头 x < −0.9、车身中段 x −0.9 … 0.8、车尾 x > 0.8；**例外：侧窗下沿 U 从 x 0.6 起归车尾**（它要一路按照片走到窗尖，在 x 0.8 截断会在俯视里出 S 弯）。
- 每个改动放在默认开的 `QF_*` 开关后面；只 `--write-lock` 自己改过的面板；合并后协调者重跑 `check.py lock` / `smooth`。
- 全部合并后：全车光顺审查（14 个视角的 h / v 斑马纹 + 数值曲率），再重建资产（压缩 + raw）、`check.py budget`、`npm test`、浏览器检查，更新 SPEC §9 / HISTORY，推送。
