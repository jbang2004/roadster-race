0. 先说三件需要协调者拍板的事
(1) 用户裁决 U-1 写的是"前轮上方（约 x -1.9 … -1.1）U 的折角 <= 10°"。我做到的是：折角从车头段的 70° 一条单调曲线降到 x -1.65 处 9.0°、x -1.60 …-1.45 处 7.0–8.1°，到 x -1.40 …-1.2 U 处肩部切线只比水平低 4.6–5.4°（那里顶面量不出折角，见 3.4）。x -1.90 … -1.70 这 20 cm 仍是过渡段：33°、24°、18°、14°、12°。原因是反射环（见 2.4）：把过渡缩短到 20–25 cm，reflect_v 就出现封闭靶心环（试了 12 个变体，j / m 系列全部有环），过渡长 >= 0.75 m 才没有环。也就是"折角 <= 10° 要覆盖到 x -1.9"与"没有反射环"在这个几何里互斥，我选了后者，数字都在下面。想要更靠前的 10° 请指示，我可以用 QF_C11_FX / QF_C11_FP 调，但会带环。
(2) reflect_h 里软肩上出现 3–4 条"回头弯"（嵌套的 U 形条纹，开口朝车头，被车头段利棱截断；它们是肩截面法线从竖直扫到水平时反射仰角的脊线，圆肩的正常样子）。没有封闭岛：检测器在软肩区只有一个 0.8 个条带的仰角峰（x -1.96, 6.1°）。如果协调者把回头弯也算"环"，那软肩与"reflect_h 无环"不能同时满足；保持利棱的那一版（h5，折角 36–47°）是无环的，开关见第 8 节。
(3) 肩部倾角变化率：c9b 的 "max rate/5cm"（上升方向）c11b 为 -0.14 / -1.09 / 0.76（z .80/.83/.76，限 2.66，PASS）；但下降方向 -10.7 / -8.8 / -6.2（c10b -2.3 / -2.6 / -2.2）。这是软化本身带来的：固定 z 处肩面法线仰角（x -1.85 到 -1.35）z .80 从 57° 降到 20°，z .83 从 75°（x -1.80）降到 33°，z .76 从 41°（x -1.95）降到 8°。若这条限是绝对值，则 c11b 不满足，且无法满足（总变化量 >= 37°，过渡 0.45 m，最小也要 4°/5 cm）。顺带：h5 的上升方向是 3.29 / 3.97 / 2.30，也超过 2.66（我之前口头报告 h5"全部限内"时没有重算这一项，请以这里为准）。

2.4 反射与"弦定理"
- 弦定理：旧 U 切线约 52°，凸弧要在唇处以小于约 40° 的切线到达，就要求 U 处的切线也软化（唇切线 + U 切线 = 2 倍弦角 ≈ 93°）。所以"软化的上棱"与"圆肩"是同一件事，不是能把一条利棱留着再另加圆弧。
- 环的成因（从 GLB 上量的，c11b_azgrid.py）：过渡太短时，肩面沿 x 先朝车头倾再回来，镜面方向的方位角沿 x 出现极小，并与沿 z 的极小重合，形成封闭极值，reflect_v 里是靶心。m2 在 z .78：x -1.85 / -1.80 / -1.75 / -1.70 / -1.65 / -1.60 处 -20 / -7 / -62 / -78 / -66 / -43 度（x -1.70 极小）；c11b 在 z .76：-79 / -77 / -70 / -57 / -44 / -36 度，沿 x 单调，只剩沿 z 的折线，没有封闭环。经验判据：过渡 >= 0.75 m 无环，<= 0.45 m 的试验（j、m）全部有环，中间长度没有测。检测器 c11b_peaks.py（直接在 GLB 上求镜面方位 / 仰角的局部极值及其"高度"，不需要渲染）与渲染一致：j4 / m2 有 2.2 个条带的方位极值（可见靶心），c11b 没有新的方位极值（reflect_closed_peaks.txt；弧唇处 y < -1.04 的峰 c10b / c11 同样有，是基线）。
- 试过的变体（Q/proof_c11b/variants/）：h5（环无）；j1–j4（过渡约 20 cm，起点 -2.15 / -1.95，靶心）；m1–m4（起点 -1.90 / -1.80，靶心）；n1–n4（-2.30 .. -1.45 / -2.20 .. -1.55 的五次斜坡，无环，但折角在 x -2.05 .. -1.95 掉 35° / 5 cm）；p1–p4（加 FP 2 / 3 延后：折角单调，最大 15°/5 cm，p1 = 出货）；q1–q3（到 U 处用恒定到达角 2 / 3 / 4.3°：回头弯没有变化，说明与顶面倾角表无关，该参数已删掉）。
- reflect_v：无环，条纹沿肩扇形展开；reflect_h：3–4 条回头弯（见 0(2)）。折角过渡段没有条纹折点（zoom/zoom_reflect_h_p016_corner_photo_c10b_c11_c11b.png）。
